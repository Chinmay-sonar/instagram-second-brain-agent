## 📖 Complete Curriculum & In-Depth Notes
### Overview
21st is a living library of interfaces built by design engineers. Unlike traditional component libraries, it functions as a registry where you own the code you copy into your repository.

### Core Offerings
- **12,000+ Components:** Includes marketing blocks, animated heroes, shaders, UI widgets, and full templates.
- **AI-Ready Integration:** Every component ships as a prompt designed for AI agents (Cursor, Claude Code, v0, Lovable).
- **shadcn/ui Compatibility:** Built to compose seamlessly with shadcn/ui primitives and existing design tokens.

### How It Works
1. **Browse:** Explore thousands of components from hundreds of authors.
2. **Copy Prompt:** Use the provided AI prompt to generate the component in your project.
3. **Install:** Alternatively, use the standard shadcn CLI install command for manual integration.
4. **Own:** The code lands in your repo, allowing for full customization without dependency versioning issues.
