## 📖 Complete Curriculum & In-Depth Notes
# Design Extractor — Turn Any Website Into a Design Doc

Design Extractor is a Chrome extension designed to help developers, designers, and indie hackers copy the look and feel of any website in 30 seconds. Instead of digging through DevTools or guessing CSS values, users can generate a structured `DESIGN.md` file with a single click.

---

## ⚡ Core Functionality
When you click **"Analyze This Page"**, Design Extractor performs the following actions:
1. **Scans the Code:** Grabs all CSS variables, fonts, colors, spacing, shadows, and animations.
2. **Takes Smart Screenshots:** Captures the top, middle, and bottom of the page so the AI has visual context.
3. **Generates a Design Doc:** Writes a clean Markdown file covering the vibe, colors, typography, components, and instructions on how to rebuild it.
4. **Exports Instantly:** Allows you to copy the output to your clipboard or download it as `{website}_DESIGN.md`.

## 👤 Target Audience
- **Indie Hackers & Devs:** Feed design specs straight into Cursor, Copilot, or v0 without guesswork.
- **Designers:** Analyze competitors and build a teardown library in minutes.

## ✨ Key Features
- **One-Click Analysis:** Works on any HTTPS page.
- **Comprehensive Extraction:** Extracts colors, fonts, spacing, shadows, gradients, animations, and component styles.
- **AI-Powered Visual Context:** Uses 3 auto-captured screenshots to guide the AI.
- **Real-Time Streaming:** Watch the markdown document write itself in real-time.
- **OpenAI-Compatible:** Bring your own API key (Kimi, GPT-4o, and more) for unlimited free usage.
- **Local-First Privacy:** Built on Manifest V3 with zero extra dependencies. Your API key is stored locally in `chrome.storage.local` and never touches external servers.
